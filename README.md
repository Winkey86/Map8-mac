# Map8 для macOS

Map8 — учебный тренажёр по физико-географической номенклатуре России для 8 класса. Это оригинальная Windows-версия программы, запускаемая на Mac через бесплатный Wine. CrossOver и Windows покупать не нужно.

Пакет проверен на Mac с процессором Apple Silicon. Он также рассчитан на 64-битные Intel Mac с современной macOS.

## Быстрая установка

1. На странице GitHub нажмите зелёную кнопку **Code**, затем **Download ZIP**.
2. Распакуйте ZIP. В полученной папке нажмите правой кнопкой на **Установить Map8.command** и выберите **Открыть**.
3. Если macOS переспросит, снова нажмите **Открыть** и дождитесь сообщения «Готово».

При первой установке нужен интернет: установщик скачает бесплатный Wine и проверит, что файл не повреждён. После установки интернет для игры не нужен.

Map8 появится здесь:

`Домашняя папка → Программы → Map8`

В дальнейшем запускайте только приложение **Map8** — установщик повторно открывать не требуется.

## Если macOS не даёт открыть установщик

Обязательно нажмите на файл **правой кнопкой мыши → Открыть**. Обычный двойной щелчок может быть заблокирован защитой macOS.

Если пункта «Открыть» всё равно нет:

1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
2. Внизу страницы найдите сообщение о заблокированном файле.
3. Нажмите **Всё равно открыть**.

## Если установка остановилась

- Проверьте интернет-соединение и запустите установщик ещё раз.
- На Mac с процессором M1/M2/M3/M4 система может попросить установить Rosetta 2. Это официальный компонент Apple; согласитесь и введите пароль администратора, если macOS его запросит.
- Не переносите отдельные файлы из папки перед установкой: папки `game` и `launcher` должны лежать рядом с установщиком.
- Технический журнал запуска находится в `~/Library/Application Support/Map8/launch.log`.

## Удаление

Удалите два объекта:

1. `Домашняя папка → Программы → Map8.app`
2. `Домашняя папка → Библиотеки → Application Support → Map8`

Вторая папка скрыта в Finder. Чтобы открыть её, нажмите **Переход → Переход к папке…** и вставьте:

`~/Library/Application Support/Map8`

## Что именно устанавливается

- оригинальные файлы учебного тренажёра Map8;
- отдельная бесплатная среда Wine Staging 11.14 только для этой программы;
- удобный значок Map8 в папке программ пользователя.

Установщик ничего не меняет в системной папке `/Applications` и не требует CrossOver.

## Происхождение и права

Оригинальная программа распространялась на сайте ЛНИП-БГ. Права на Map8 и её материалы остаются у их правообладателей. Wine скачивается из проекта Gcenx/macOS_Wine_builds и в этот репозиторий не включён. Скрипт совместимости и оболочка запуска не являются изменённой версией самой учебной программы.
