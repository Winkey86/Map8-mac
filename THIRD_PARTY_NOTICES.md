# Сторонние компоненты

## Map8

В каталоге `game` находятся исходные файлы учебного тренажёра Map8, ранее распространявшегося сайтом ЛНИП-БГ. В найденном дистрибутиве отдельный файл лицензии отсутствует. Авторские права на программу и учебные материалы принадлежат их правообладателям.

## Wine Staging

Установщик загружает Wine Staging 11.14 из релизов проекта Gcenx/macOS_Wine_builds:

https://github.com/Gcenx/macOS_Wine_builds/releases/tag/11.14

Архив Wine не хранится в этом репозитории. Перед распаковкой установщик сверяет SHA-256:

`cc8ff0f2f95e26e591d049092c16898f10718b7c74addfbf6498ad06ca3bab42`
